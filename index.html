Financial fair play, replayed · 2009–2026

The Premier League, minus Manchester City

An independent Premier League commission has just found Manchester City guilty of financial rule-breaking spanning nine seasons. So here's the league, rebuilt from real match results, as if City were never in it — not just for those nine seasons, but for all seventeen completed since, plus the one being played right now.

Who actually needed Manchester City?

Removing a team can only ever cost the rest of the league points, never hand any out — you can lose only the points you genuinely won off Manchester City, never gain points you didn't. So this is a one-way leaderboard: total points each club banked directly from fixtures against City across all 17 completed seasons, 2009/10–2025/26. The traditional "big six" dominate it — mostly earned in City's earlier, less dominant years, before the closer meetings of the 2020s dried the well up.

Sources on the verdict.

Method. Match-by-match results for every season sourced from football-data.co.uk. "Actual" tables are standard 3/1/0 recalculations from full results (20 clubs, 38 games; the 2026/27 table is a partial in-progress snapshot). "No Man City" tables exclude every fixture involving Manchester City and rebuild the table from the remaining results for the other 19 clubs (36 games each), using the Premier League's own tiebreakers (points, then goal difference, then goals scored). Rank-change badges compare each club's position with City's row simply deleted (renumbered 1–19) against its position in the properly recalculated table — so a badge only appears when a genuine swing in results, not just a vacated slot, moved a club. Historical administrative points deductions (e.g. Portsmouth, 2009/10 and 2010/11) are not applied, since this is a pure results recalculation; this affects final points totals for a small number of already-relegated clubs but not the season's storylines. This project does not model any sanction — none has been set — it only recalculates results that were actually played.
